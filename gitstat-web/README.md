# GitStat.Web

The official web presence and social sharing engine for the GitStat macOS menu bar utility.

## 🚀 Vision
GitStat.Web bridges the gap between local development activity and social impact. It allows developers to:
- Generate high-fidelity "Impact Cards" for social media.
- Visualize 1B+ line-of-code milestones with the Brutalist Ticker.
- Download the native macOS utility for real-time menu bar tracking.

## 🛠 Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Runtime**: Bun
- **Styling**: Tailwind CSS 4 + Framer Motion
- **Icons**: Lucide React
- **Capture**: html-to-image

## 📦 Getting Started

```bash
cd gitstat-web
bun install
bun dev
```

## 🎨 Aesthetic Direction
**Technical Brutalist**: Heavy typography, structural grid overlays, high-contrast monochrome with GitHub green accents, and hardware-inspired layouts.
